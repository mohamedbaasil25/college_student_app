# Ponjesly College of Engineering App

A comprehensive PJCE portal application built with HTML, CSS, and Vanilla JavaScript.

## Features
- **Secure Login**: PJCE portal authentication (Mock credentials pre-filled).
- **Dashboard**: Quick access to all services.
- **Profile**: View student details (Register No, Address, etc.).
- **Fees**: Check payment status and outstanding balance.
- **Results**: Deep link to semester results.
- **Bus Pass**: Digital bus pass with ID details.
- **Contact**: Quick contact links for college administration.

## Visuals
The app features a premium dark/glassmorphism design with smooth animations and responsive layout, optimized for mobile devices.

## How to Run
1. Navigate to the project folder (`c:/hsh`).
2. Double-click `index.html` to open it in your web browser.
3. Use the pre-filled credentials to log in.

## Project Structure
- `index.html`: Main application skeleton and templates.
- `style.css`: Premium styling system.
- `script.js`: Application logic and routing.
